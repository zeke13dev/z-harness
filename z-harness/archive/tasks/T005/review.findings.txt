## Codex review: task T005

### Blockers

- **Phase 5 Step 2c dispatch issue** (`commands/z-uplift.md:2130-2140`): Phase 5 does not invoke or wait for `/z-implement-all`; it marks the row `[i] implementing`, tells the user to run another command, exits, and never performs the required `[x] done` transition on completion. Fix by actually dispatching `/z-implement-all --tasks="$COMP_TASKS_MD"`, waiting/resuming at that pause point, validating the TASKS.md has no pending `[ ]` tasks, then marking `[x] done` and emitting `component_implement_done`.

### Major

- **Unchecked manual-done transition** (`commands/z-uplift.md:2140, 2203-2210`): "Mark as done" is user-asserted and does not verify that the dispatched TASKS.md is complete, so MANIFEST can become `[x] done` while component tasks are still pending. Fix by reading `COMP_TASKS_MD` before any `[x] done` transition and refusing/continuing `[i] implementing` if pending task markers remain.

- **Cross-cutting detection mismatch** (`commands/z-uplift.md:2009-2011`): Cross-cutting-first detection does not match the actual synthetic row format (Component=`<slug>-cross-cutting`, Slug=`(global)`), causing "regardless of physical position" ordering guarantee to fail if row is moved. Fix to recognize `comp == f"{slug}-cross-cutting"` or `row_slug == "(global)"`, and normalize slug.

- **Phase 4 checkpoint overwrite** (`commands/z-uplift.md:1954`): Phase 4 writes summary checkpoint at `phase4-review-gate.md` then immediately overwrites it with `MANIFEST.md`, destroying the review-gate artifact. Write MANIFEST checkpoint to distinct archive filename such as `phase4-manifest.md`.

- **Non-atomic MANIFEST updates** (`commands/z-uplift.md:2120-2126, 2173-2179`): MANIFEST helper silently succeeds when matching zero rows and updates all duplicates, violating "atomic per component" correctness. Track replacement count, require exactly one matched row, write temp file only on success, fail loudly otherwise.
